⬇️ Descarregar Backup

Transfira a cópia integral e consolidada da base de dados ativa (retaillaunch.sqlite). Ideal para salvaguarda ou para migrar os dados do Mac (Localhost) para o Synology NAS.

⬆️ Restaurar / Migrar Dados

Carregue um ficheiro .sqlite para substituir a base de dados deste servidor. O sistema cria automaticamente uma cópia de segurança de salvaguarda (.bak) antes da substituição.

💡 Como funciona a persistência contínua no Synology NAS?

1. No Synology NAS, os dados residem no volume Docker retaillaunch_data.
2. Como a base de dados está em .gitignore, futuros git pull origin main nunca apagam nem substituem os dados do NAS.
3. Ao reconstruir o contentor com docker compose build --no-cache && docker compose up -d --force-recreate, o volume preserva todos os dados intactos.
